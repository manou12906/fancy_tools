# Fancy Tools

## Description
Outils pour simplifier l'utilisation de Git avec des alias et fonctions shell personnalises
installer des daemons .

## Prérequis
- Linux 
- Git installé
- Bash

## Installation
pour installer, il faut etre dans le repository du projet puis entrer la
commande:
"bash install.sh"

##Utilisation
•gss → git status
•gpl → git pull
•gpu → git push
•gap → git add .
•gco “message” → commit avec branche

fancy_tools/
├── .aliases
